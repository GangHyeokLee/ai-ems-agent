# Light/Dark 테마 · 모델/AI Assistant 도움말 (Issue #6)

물리계산, API, 데이터는 변경하지 않았다. KPG·몽골 모두 같은 테마 진입점과 도움말 컴포넌트를 사용한다.

## 테마

- 헤더의 **Light / Dark / System** 라디오 그룹(네이티브 radio, 방향키·Tab 사용 가능)으로 전환한다. 기본값은 System이며 OS의 `prefers-color-scheme`을 따르고, OS 설정이 바뀌면 즉시 반영한다.
- 사용자가 고른 값은 `localStorage["ai-ems-theme"]`에 저장한다. `<head>`의 인라인 스크립트가 첫 렌더 전에 `html[data-theme]`을 적용하므로 새로고침할 때 화면이 깜빡이지 않는다. 계통을 전환해도 테마는 유지된다.
- 디자인 토큰은 `:root` / `:root[data-theme="dark"]`의 CSS custom properties로 정의한다. 토큰 범위는 배경·표면·테두리·텍스트·입력·버튼·오버레이·팝오버·경고·오류·채팅·코드·지도 배경·경계·선택 강조다. `color-scheme`도 함께 바꿔 네이티브 컨트롤과 스크롤바가 테마를 따른다. 계통별 CSS를 따로 두지 않았다.
- **데이터 색상**(전압 등급, PF 구간, 발전원, 발전기)은 Light에서 기존 값을 그대로 쓴다. Dark에서는 `dataColor()`가 같은 계열의 밝은 tint로 바꿔 어두운 지도 배경 대비 3:1 이상을 확보한다(측정 최솟값: 선로 3.22, 모선 5.72, 발전소 4.88). 테마를 전환하면 지도와 PF 범례를 즉시 다시 칠한다.
- 분석 오버레이는 색상만으로 구분하지 않는다.

| 오버레이 | 표현 |
|---|---|
| 사고 선로 | 실선 |
| 위반 설비 | 긴 점선 (이번에 추가) |
| 감시 선로 | 짧은 점선과 링 |
| 분리 모선·선로 | 점선 |
| 민감도 후보 | 번호 사각형 |

모든 오버레이는 범례에 라벨로 표시된다.

## 도움말 팝오버 (공통 컴포넌트 `setupHelp`)

- 트리거는 `<button aria-haspopup="dialog" aria-expanded aria-controls>`, 패널은 `role="dialog"`, `aria-labelledby`, `tabindex=0`(긴 내용 키보드 스크롤)이다. 단순 `title` 툴팁은 사용하지 않는다.
- hover로 열고, 떠나면 250 ms 후 닫는다. 클릭·탭이나 Enter·Space로 고정해서 열 수 있다. 바깥을 클릭하면 닫히고, Escape로 닫으면 포커스가 트리거로 돌아간다. 한 번에 하나만 열린다.
- `position: fixed`로 뷰포트 안에 고정하고, 공간에 따라 위나 아래로 연다. `max-height`와 스크롤을 적용하며 resize·scroll 때 위치를 다시 계산한다(`z-index: 1000`).

### 모델 정보 (PR #8 리뷰 반영)

- 상시 합성 데이터 배너(`합성 … · 실제 운영 데이터 아님`)는 화면에서 제거했다. 빈 행이 남지 않도록 배너 행 자체를 없앴다.
- **ⓘ 모델 정보** 버튼은 계통 선택 옆(`.grid-toolbar`)에 있다. 팝오버는 기존 고지문 전문(첫 문장), PF 상태(수렴·반복), 모델 파일·snapshot·설비 수, 합성 설비, HVDC 제외·모델 한계, **현재 상태**(정상 상태 문구), 계통 기능 범위(카탈로그 note)를 원문 그대로 담는다.
- `#grid-status`는 비정상 상태만 상시 표시한다. 미등록, 지도 준비 중·오류, 계통 목록 오류, PF 미리보기 사용 불가, 계통해석 미지원·미검증이 여기에 해당한다. 정상 문구(`계통해석 가능`, `합성 PF 미리보기 · 선로 N-1 Security / Sensitivity Analysis 가능` 등)는 `setGridStatus()`를 거쳐 도움말의 "현재 상태"에만 기록한다.
- PF 미리보기 오류(`#pf-preview-alert`)와 Security·Sensitivity 비활성 사유(`#grid-capability-note`)는 오류 행으로 상시 표시한다.
- 줄바꿈 규칙은 다음과 같다.
  - 팝오버 폭은 첫 문장 길이에 맞춘다(`width: max-content`, 최대 760 px·뷰포트 이내). 첫 문장은 `nowrap`으로 한 줄에 표시하고, 뷰포트가 좁아 들어가지 않을 때만 `wrap-first`로 줄바꿈을 허용한다.
  - 나머지 블록은 `contain: inline-size`로 폭 결정에서 제외한다. `word-break: keep-all`(한글 어절 단위)과 `overflow-wrap: break-word`(긴 파일명)를 적용한다.

### 상시 안내 정리 (일반 안내·반복 고지 제거, 경고 보존)

| 이전 상시 표시 | 이동 위치 |
|---|---|
| PF 범례 아래 기준 문구(모선 전압 한계, "PoC 시연용 시각화 구간… 운영 경보 기준 아님", MVA 기준) | ⓘ 모델 정보 › 지도 표시 기준 |
| "Security/Sensitivity 사고 결과 강조가 PF 색상보다 우선…" | ⓘ 모델 정보 › 지도 표시 기준, ⓘ 사용 안내 › 분석 패널 |
| 결과 카드 하단 합성 고지 4종(KPG·몽골 × Security·Sensitivity) | ⓘ 모델 정보 › 분석 결과 해석 (몽골은 상세 결과의 모델 주의사항에도 유지) |
| 모선·선로·변압기 툴팁의 반복 모델 출처 문구 | ⓘ 모델 정보 › 모델 출처·한계 |
| 분석 패널 기본 안내 문구, "지도에서 발전기 행을 클릭하면…" | ⓘ 사용 안내 › 분석 패널 (계통별 자동 선택 규칙 포함) |
| 대표 사고 선택의 "(몽골 합성 시나리오 검증 사례)" | 삭제 (모델 정보에 합성 고지 존재) |
| 설비 범례 주석(KPG 클릭 안내 / 몽골 "레코드 기준·중복 가능·용량/연결 검증 전") | 클릭 안내는 사용 안내로, 몽골 데이터 한계는 ⓘ 모델 정보 한계로 |

**상시 표시를 유지하는 항목**

- 계통 상태 이상: 미등록, 지도 준비 중·오류, 계통 목록 오류, PF 미리보기 사용 불가, 계통해석 미지원·미검증
- PF 오류와 Security·Sensitivity 비활성 사유
- 계통 분리 알림(주 계통만 수렴, 분리 섬 PF 미실행), 비수렴 시 판정 불가
- Sensitivity 미평가(계통 분리)·비수렴·미지원 메시지, 발전기 탈락 분석 미지원
- 입력 변경 후 결과 초기화 안내, 채팅 오류

### AI Assistant 사용 안내

- 패널 제목 옆 **ⓘ 사용 안내**로 연다. 몽골 채팅 로그에 넣던 긴 시스템 안내를 이 팝오버로 옮겼다.
- 몽골: 합성 PF 조회 전용, AI 채팅에서 N-1 호출 불가, 선로 N-1과 (계통 분리 없는) Sensitivity는 패널에서 실행, Redispatch 미지원, 예시 질문 3개를 원문 그대로 담는다.
- KPG: 기존 Agent Tool 범위(선로 N-1, 민감도, 발전기 탈락·비교·Screening, 대응방안/Redispatch 후보 검토 — 최적 Redispatch 아님), 합성 시험계통 고지, 예시 질문을 담는다.
- 채팅 장애와 실패 메시지는 기존처럼 채팅 로그에 표시한다.

## 검증

```bash
.venv/bin/python -m pytest -q tests
AI_EMS_BROWSER_TESTS=1 .venv/bin/python -m pytest -q tests
```

`tests/browser/theme_help_probe.js`(Chrome, 실제 API)는 단계별로 진행하며, 새로고침 전후 상태를 함께 검증한다. 확인 항목은 다음과 같다.

- 테마 상태
  - 기본 System과 OS 변경 반영
  - Dark 선택 시 저장, 적용, `color-scheme` 전환
  - 새로고침 후 Dark 유지, Light·System 전환과 저장
  - 계통 전환 후 테마 유지
  - 테마 전환 시 데이터 색상 재적용
- Dark 테마에서 KPG·몽골 Security·Sensitivity 실행
- 대비 측정
  - 텍스트 4.5:1 이상 18곳(헤더, 배너, 결과, 범례, 레이어, 입력, 팝오버, 경고·오류 등)
  - 지도 선로·모선·발전소 3:1 이상
- 도움말 동작: hover, 클릭 고정, 바깥 클릭, 키보드 열기, Escape와 포커스 복귀, ARIA, 뷰포트 안, 하나만 열기
- 도움말 내용: 계통별 원문 보존, 다른 계통 문구 미혼입
- 상시 안내 정리: 결과 카드·범례·패널에 일반 안내와 합성 고지가 없음, 이동한 문구가 도움말에 존재함, 경고(계통 분리·미평가·미지원·PF 오류·비정상 상태)가 Light와 Dark에서 상시 표시됨
- 테마별 확인: 테스트 PC의 OS가 Dark여도 Light를 명시 선택해 Light 결과·대비를 검증하고, System은 OS 변경 시뮬레이션으로 양방향을 검증
- PR #8 리뷰 항목: 상시 배너 없음과 빈 행 없음, 정상 상태 비표시와 도움말 기록, 비정상 상태 상시 표시, 첫 문장 한 줄(데스크톱), 한글 어절 중간 줄바꿈 0건(Range로 실제 줄 위치 측정), Dark 오버레이(사고·위반·감시) 대비 3:1 이상
- 장애 표시: 실패 알림 상시 표시

작은 창(820×640)에서도 도움말 위치와 동작을 따로 검증한다. 결과와 대비 수치, 스크린샷은 `outputs/browser_theme_help/`에 저장된다.

## 알려진 한계

- Light 테마의 기존 데이터 색상 일부는 밝은 지도 배경 대비가 낮다(PF 50–80 % 노랑 1.75:1, 앰버 계열 1.96:1). Light 색상 의미를 바꾸지 않기 위해 이번에는 유지했고, 선 굵기·점선·범례 라벨로 보완한다.
- 지도 영역이 매우 낮을 때(약 300 px 이하) 좌상단 분석 범례와 좌하단 설비 범례가 겹칠 수 있다(Issue #5 배치).
