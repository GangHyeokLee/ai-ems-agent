보관 파일은 [latest-demo.html](latest-demo.html)이며 실제 EMS 서버가 제공한 계산 결과가 아니다.

- 확인일: 2026-11-04 (Asia/Seoul), DOC-01.
- 출처: 사용자가 `local-reference/`에 추가한 `계통 관제 의사결정지원 테스트베드 (최신).html`.
  생성 대화 URL·작성 시각은 제공되지 않아 파일명과 실제 바이트를 기준으로 식별했다.
- 기존 회귀 원본: `local-reference/계통 관제 의사결정지원 테스트베드 (데모).html`.
  회귀 원본과 최신 로컬 파일은 수정하지 않았다.

## 현재 `/console/`과의 관계

현재 콘솔은 기존 회귀 원본의 CSS·모델·JavaScript를 `ui/console/app.css`, `models.js`, `app.js`로
분리하고 `index.html`에 연결한 구조다. 원형 슬라이스·마크업 해시는 기존 테스트가 고정한다.
실제 EMS API 계통의 지도·PF·N-1·Sensitivity와 PH4-01 채팅은 별도 `api-*` 모듈에서 연결한다.

이 보관 파일은 정적 참고 자료이며 콘솔 자산 허용 목록이나 서비스 경로에 추가하지 않는다.
콘솔의 원형 파일·현재 HTML·기능 모듈·검증 해시를 이 파일로 덮어쓰지 않는다.
향후 디자인 반영은 요구사항과 API/capability 경계를 확인한 별도 작업으로 진행한다.

## 모의 데이터와 게시 점검

HTML 내부의 브라우저 DC 계산·규칙 기반 채팅·모의 실시간 피드·MCP/데이터 레이크/학습 화면은 데모다.
화면의 결과·평가·보고서·학습 상태를 실제 PyPowSyBl 계산이나 배포된 EMS/LLM/학습 인프라의 증거로 사용하지 않는다.
KPG 시험계통 모델과 출처 표시는 원문을 유지한다(`agm-center/kpg-testgrid`, ODbL 1.0).

정적 검토에서 API 키·인증값·비밀키·실제 내부 IP/개인 절대 경로는 발견되지 않았다.
`fetch`·XMLHttpRequest·WebSocket 호출이 없고 외부 URL 속성은 Google Fonts 3개뿐이다.
브라우저 저장소를 사용하는 데모이므로 원본 실행과 실제 서비스의 동작을 구분한다.
기존 KPG 모델·지도 출처 고지를 유지하며 새로운 독점 이용·재배포 권한을 부여하는 문서가 아니다.

## 향후 UI 표준으로 참고할 요소

- 계통 선택·출처·모드 표시, 주요 KPI와 경보의 일관된 배치.
- 지도와 의사결정지원 패널의 공존, 선택 설비 카드·검색·범례와 결과 강조.
- 질문·답변·처리 중·실패 상태, 패널 접기/펼치기와 입력 초안 유지.
- 색상·간격·타이포그래피, 키보드 조작과 ARIA 상태 등 접근성 패턴.
- 데모/실제 API, 합성/실측, 지원/미지원, 기존 결과/새 실행 결과의 명확한 구분.

기능 지원 여부와 신뢰할 수 있는 계산 결과는 항상 현재 서버 계약과 검증된 물리해석 결과를 기준으로 한다.
