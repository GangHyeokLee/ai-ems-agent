# 한국 OSM 송전망 데이터 파이프라인 통합 및 토폴로지 검증

작성: 2026-10-26(코드 리뷰 후속 수정 반영). 작업 기준은 `feature/kr-osm-map-integration` `493c972`(원격 `feature/kems-multi-grid`와 동일)이다. 한국 AC PF 준비 상태는 계속 `NOT_READY`이며, 이번 작업은 계산 기능을 활성화하지 않았다.

## 1. 기존 구조 분석

### 한국 데이터 디렉터리(`~/Projects/korea-grid-poc`, Git 저장소 아님)

| 구성 | 내용 |
|---|---|
| 원본 | Geofabrik `south-korea-261020.osm.pbf`(ODbL, SHA256 `74c2033a…`, 2026-10-20T20:23:47Z), WRI GPPD v1.3.0 zip, geoBoundaries KOR ADM1 |
| 독립 파이프라인 | Snakefile: `check_sources` → `extract_osm.py`(pyosmium) → `import_powerplants.py` → `build_kr.py` → `validate.py` → `render_map.py` → `write_reports.py` |
| 산출물 | `networks/KR/base.nc`(PyPSA), `outputs/map/kr_grid_preview.json`, `reports/*`(검증, 제외 객체, 교차·공유 지지물 의심 목록, 성분 목록) |
| PyPSA-Earth | `pypsa-earth/` 소스 스냅샷(508 MB, `23fa6edf`). 공식 규칙은 설정 검증·진단용으로만 실행했다. `base.nc`는 공식 워크플로가 아니라 `build_kr.py`가 만든다 |
| 환경 | 독립 `.venv` 1.7 GB(PyPSA 1.2.4, Snakemake 9.27, pyosmium, shapely, geopandas 등) |

`build_kr.py`가 지도와 계통 모델을 함께 만든다. 같은 모선·선로 목록을 `base.nc`와 지도 JSON에 쓰므로, 지도와 모델은 같은 그래프다. 그래프는 다음 규칙으로 만든다.

- 모선은 (OSM 노드, 전압) 쌍이다.
- OSM way는 같은 전압의 다른 way와 공유하는 노드에서만 나눈다.
- 거리 병합, 교차 연결, 전압 간 연결, 변압기 추정은 하지 않는다.

기존 보고값 426은 이 그래프에 `networkx.connected_components`를 적용한 결과다.

### AI-EMS Agent에서 이미 하던 일

- `scripts/import_kr_osm_map.py`: 원본 지도를 검증해 배포 지도를 만든다(`load_korea_map` 재사용).
- `scripts/build_kr_land_boundary.py`: OSM 해안선으로 육지 경계를 만든다(오프라인 osmium 환경).
- `src/ai_ems/grid_catalog.py`: 지도 검증과 Grid Catalog를 담당한다. 한국은 지도만 지원한다.

### 통합 범위 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| OSM 추출·`build_kr.py`·Snakemake | 외부 유지, 산출물을 읽기 전용 입력으로 사용 | PyPSA·pyosmium·Snakemake 등 1.7 GB 환경이 필요하다. AI-EMS 실행 환경과 분리해야 한다 |
| PyPSA-Earth 소스·Pixi | 복사하지 않음 | 한국 모델 생성에 실제로 쓰이지 않는다(진단용) |
| 토폴로지 분석·검토 후보 | **AI-EMS `pipelines/kr/`로 통합** | 가벼운 의존성(numpy, 기존 선언된 h5py)으로 실행할 수 있다. 이후 전기 모델 구축의 기초다 |
| 지도 검증 | 기존 `load_korea_map` 재사용 | 중복 구현을 피한다 |
| 다른 국가 공통화 | 이번에는 하지 않음 | 몽골 파이프라인과의 실제 중복을 아직 확인하지 않았다. 입력 어댑터·그래프 분석은 국가 독립적으로 작성했다 |

## 2. 통합한 코드

```text
pipelines/
├── __init__.py
└── kr/
    ├── README.md            # 단계·입력·실행 방법
    ├── sources.py           # 지도 JSON / base.nc(h5py) / OSM 객체 어댑터, ID·참조 검증, SHA256
    ├── topology.py          # union-find 연결 성분, 통계, 전압별 분석, 입력 간 비교
    ├── candidates.py        # 접속 검토 후보, 거리 계산, 섬 위치, 가설적 민감도
    ├── report.py            # 한국어 보고서
    └── analyze_topology.py  # CLI(python -m pipelines.kr.analyze_topology)
tests/test_kr_topology_pipeline.py
```

실행 방법은 다음과 같다.

```bash
.venv/bin/python -m pipelines.kr.analyze_topology --korea-project ../korea-grid-poc --output-dir outputs/kr_topology
```

자세한 단계·인자는 `pipelines/kr/README.md`를 참조한다.

수정하지 않은 것은 다음과 같다.

- 지도 API·Grid Catalog·UI
- 기존 import·해안선 스크립트
- KPG·몽골 계산 코드, Caddy
- `korea-grid-poc`·`mongolia-grid-poc`

새 의존성은 추가하지 않았다.

### 기존 426과의 비교

입력 세 개에서 같은 결과가 나왔다.

- `base.nc`, 원본 지도, 배포 지도의 모선 ID·선로 ID·선로 양단이 모두 같다.
- 세 입력의 연결 성분 구성(성분별 모선 집합)이 같다.
- 원본 지도에 저장된 `component_id`도 그대로 재현된다.

426은 "OSM 노드 + 전압 모선, 같은 전압 공유 노드에서만 연결, 변압기 없음" 그래프의 값이며, 이번 계산과 정의가 같다. 이 값은 실제 전력계통의 섬(island) 수가 아니다.

### B. 연결 단절 원인

| 원인 | 판정 | 근거 |
|---|---|---|
| 다른 전압 간 변압기 접속 누락 | **모델 정의로 확정** | 모델에 변압기가 0개라서 다중 전압 성분이 0이다. 완벽한 데이터라도 최소 3개 성분이다. 같은 OSM 변전소 안의 다른 전압 성분 쌍 230개(후보 240건). 어느 변전소에 어떤 변압기가 있는지는 미확인이다 |
| 변전소 내부 연결정보 누락 | 데이터 근거 있는 후보(미검증) | 같은 OSM 변전소 영역 안의 같은 전압 성분 쌍 367개(후보 384건). 선로 끝점 2,256개 중 1,481개가 변전소 영역 안에서 끝난다. 이 쌍이 모두 연결이라면 426 → 185 |
| 인접하지만 OSM 노드가 다른 끝점 | 데이터 근거 있는 후보(미검증) | 같은 전압 성분 쌍의 최근접 모선 거리: 10 m 이내 68, 50 m 345, 100 m 470, 200 m 557쌍. 끝점에서 다른 성분 선로 경로 위 최근접점까지 50 m 이내 1,225건(366쌍, 그중 362쌍은 근접 모선 후보와 중복) |
| 전처리에서 제외된 선로 | 데이터 근거 있는 후보(미검증) | 제외 841개(전압 누락 798, 대상 외 전압 36, DC 3, 폐합 3, 미지원 1). 그중 126개가 모델 노드를 공유하고 8개가 서로 다른 성분을 잇는다. 그중 1개(`way/143990774`, 380 kV, 대상 외 전압)는 성분 75·109·291 세 개에 닿아 성분 쌍 후보는 10건이다 |

**해석:** 성분 수가 큰 가장 큰 구조적 이유는 두 가지다. 첫째, 변압기가 없어서 전압별로 반드시 분리된다(정의상 확정). 둘째, 선로가 OSM 변전소 안의 서로 다른 인출 노드(portal 등)에서 끝나고 변전소 내부 모선이 OSM에 없다. 두 번째는 데이터가 뒷받침하지만 개폐 상태·모선 구성이 없어 확정할 수 없다.

가설적 민감도(모델 미반영)는 후보가 모두 실제 접속이라고 가정한 상한 효과다.

| 가정 | 성분 수 |
|---|---:|
| 같은 변전소·같은 전압 후보 모두 연결 | 185 |
| 같은 전압 후보 모두 연결 | 65 |
| + 제외 선로 연결 | 62 |
| + 다른 전압 후보까지 연결 | 34 |

### C. 접속 검토 후보

총 2,817건이다. 서로 다른 성분 쌍은 918개, 같은 전압 성분 쌍은 570개이며, 후보가 있는 성분은 426개 중 400개다. 기본 검토 거리는 모선 간 200 m, 끝점-경로 50 m이다.

| 유형 | 후보 | 성분 쌍 |
|---|---:|---:|
| 같은 변전소·같은 전압 | 384 | 367 |
| 같은 변전소·다른 전압 | 240 | 230 |
| 같은 OSM 노드·다른 전압 | 100 | 44 |
| 근접 모선·같은 전압 | 557 | 557 |
| 근접 모선·다른 전압 | 301 | 301 |
| 끝점-경로 근접·같은 전압 | 1,225 | 366 |
| 제외 선로가 성분 연결(선로 8개) | 10 | 10 |

후보마다 다음을 기록한다(`connection_candidates.csv`).

- 양측 모선·OSM ID·성분·전압·위경도·OSM 태그와 각 모선의 역할(`a_bus_role`, `b_bus_role`)
- 거리(m)와 그 측정 대상(`distance_target`), 근거, 의심 사유, 확인에 필요한 정보
- 같은 성분 쌍의 다른 후보 유형(`also_types`)

`distance_m`은 `distance_target`에 따라 의미가 다르다.

| `distance_target` | 후보 유형 | `distance_m`의 의미 |
|---|---|---|
| `bus_to_bus` | 같은 변전소, 같은 OSM 노드, 근접 모선 | a 모선과 b 모선 사이 거리 |
| `a_bus_to_line_route` | 끝점-경로 근접 | a 모선(차수 1 끝점)에서 상대 선로(`line_id`) 경로 위 최근접점(`route_nearest_latitude`, `route_nearest_longitude`)까지 거리 |
| `not_applicable` | 제외 선로 연결 | 거리 없음(OSM 노드 공유가 근거) |

끝점-경로 후보의 b 모선은 접근한 선로의 가까운 끝 모선(`b_bus_role=end_bus_of_approached_line`)이다. 측정 지점이 아니므로 a–b 모선 거리는 `a_to_b_bus_distance_m`에 따로 적는다. 예: `KR-TOPO-01217`은 경로까지 32.98 m이지만 a–b 모선 거리는 15,977.86 m이다.

제외 선로가 세 개 이상 성분에 닿으면 모든 성분 쌍을 후보로 만든다. 각 후보에 `excluded_way_osm_id`, `excluded_way_voltage`, 닿는 성분 전체(`excluded_way_components`)를 적는다. 전압이 없거나 대상 밖인 선로이므로 전기적 연결로 확정하지 않는다.

모든 후보는 `status=unverified`이다. 거리·변전소 포함·교차만으로 연결하지 않았고, 다른 전압 사이에 변압기를 만들지 않았다.

1. **토폴로지 개선 우선순위**
